# ZOMBIE-404 v0.10 — QA de expediciones

## Qué cambia

- **Contenedores parciales:** si solo cabe una parte de un botín, el resto permanece en la misma ubicación. Se conserva entre guardados, sin duplicarse. Las partidas v0.9 sin `remaining` siguen cargando.
- **Combate:** los ataques no seleccionan blancos detrás de paredes del mapa o de interiores. El sonido corresponde al arma realmente utilizada, y el combate cuerpo a cuerpo genera menos ruido.
- **Migración del equipo:** los contadores de munición y vendas se transfieren al inventario respetando su capacidad libre.
- **Regresiones:** cinco pruebas nuevas para saqueo parcial, persistencia, callbacks no válidos, visibilidad y peso del equipo.

## Reproducir en un ordenador con acceso a npm

```sh
npm install
npm test
npm run build
npm run dev
```

Abrir http://localhost:4040, empezar partida nueva, entrar al mercado, llenar la mochila, recoger parte de la despensa, regresar a la masía (`R`), volver al mercado y recoger lo que falte. Guardar con `P` antes de salir y comprobar el resto tras cargar. Comprobar también que los disparos no dañan zombis situados detrás de paredes.
