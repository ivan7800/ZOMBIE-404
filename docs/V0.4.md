# v0.4.0 — Atmospheric pass (experimental)

## Implementado
- Suelo con detalles deterministas de grietas, vegetación y marcas de carretera.
- Fachadas con ventanas, juntas y tejados reforzados.
- Supervivientes e infectados con extremidades, vestuario y movimiento procedural sencillo.
- Lluvia estilizada y velo atmosférico ligado al tiempo de juego.
- Sin nuevos assets externos ni modificaciones del formato de guardado.

## Limitaciones verificadas
- Estos gráficos siguen siendo ilustraciones vectoriales/procedurales, **no realismo fotorrealista ni sprites definitivos**.
- La lluvia se dibuja con Graphics en cada fotograma: requiere medir rendimiento en hardware real.
- No se pudo compilar ni ejecutar navegador: npm install falla por DNS (EAI_AGAIN). Las pruebas Node sí se ejecutaron.

## Próximos criterios de aceptación
1. Ejecutar `npm install && npm run build && npm test` en un equipo con conexión.
2. Probar movimiento, colisiones, saqueo, cambio de personaje, guardado y carga.
3. Capturar pantalla y medir FPS en Chrome y Firefox a 1080p.
4. Sustituir geometría procedural por atlas de sprites originales y tiles pintados.
5. Añadir un test de extremo a extremo con Playwright y grabación de partida.
