# ZOMBIE-404 · Tierra Muerta 0.14.1

## Lanzamiento local

Esta entrega conserva el juego y la campaña de 0.14.0 y añade dos lanzadores para la distribución ZIP:

- `JUGAR-WINDOWS.bat`: verifica Node.js 22 o superior, arranca el servidor local en una ventana dedicada y abre la dirección del juego en el navegador predeterminado.
- `JUGAR-LINUX.sh`: verifica Node.js 22 o superior, arranca el servidor local, abre el navegador con `xdg-open` o `gio` y mantiene la terminal abierta para poder detener el servidor con Enter.

Los lanzadores usan la compilación incluida en `dist/`; no ejecutan `npm install` ni descargan dependencias. Hace falta que Node.js 22 o superior esté instalado. Esta entrega no incluye instaladores nativos `.exe`, AppImage o `.deb`.

## Verificación

Los lanzadores y las instrucciones se han añadido a la distribución. El arranque gráfico en Windows y Linux debe confirmarse en equipos de destino; los scripts no sustituyen la validación manual de la campaña ni las pruebas de los instaladores Electron.
