# ZOMBIE-404 · Pixel art isométrico

El mundo usa un atlas raster con piezas de suelo de 32 × 16 píxeles y sprites con anclajes de suelo. Phaser amplía las texturas sin suavizado. El terreno exterior se compone una sola vez. Cada interior compone su suelo al visitarlo y reutiliza las paredes y el mobiliario en las visitas siguientes. Personajes, coche y objetos se ordenan por la posición de sus pies o de su base.

La paleta combina piedra, teja, pino y metal gastado. Cada uno de los siete interiores tiene su propio tratamiento de suelo, paredes y mobiliario. La masía, la gasolinera, el almacén, el refugio, la central, el centro de investigación, el repetidor y el punto de evacuación tienen elementos reconocibles. El objetivo activo conserva un marcador visible sobre el edificio. La lluvia respeta la preferencia del sistema de reducir el movimiento.

La geometría jugable, el sistema de colisiones, las decisiones, el audio y el esquema de guardado permanecen en sus módulos originales. Usa la misma dirección y el mismo perfil del navegador para continuar una partida local anterior. Para iniciar el juego descomprime la carpeta y ejecuta el lanzador de tu sistema con Node.js 22 o superior.

## Verificación

- 71 pruebas aprobadas con `npm run check`. Compilación TypeScript y Vite completada. El tamaño del bloque JavaScript sigue produciendo el aviso de Vite.
- Banco de render con texturas y escena instrumentadas. Se comprobaron el exterior, los siete interiores y la vuelta al exterior, además de que el dibujado no mutara los datos de partida. Las vistas en `capturas/v0.15/` se obtuvieron con ese banco.
- El lanzador de Linux sirvió el HTML, JavaScript, CSS, manifiesto y service worker por HTTP. Se comprobó la solicitud de apertura de la URL con un sustituto de `xdg-open` y que Enter detuviera el servidor.
- Chromium no arrancó por una restricción de sockets del entorno. Queda pendiente verificar el render y una partida completa en un navegador real, además del arranque gráfico en Windows y en móviles.
