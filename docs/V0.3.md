# v0.3 — Supervivencia táctica (incremento experimental)

## Incluido
- Inventarios individuales iniciales con límite de peso, API de añadir/consumir y migración no destructiva de partidas v0.2.
- HUD con mochila y distinción cromática de Aina, Pau y Laia.
- Detección de visión bloqueada por edificios y búsqueda de rutas en cuadrícula para persecución cuando el objetivo está oculto.
- Pruebas unitarias reproducibles de inventario, migración, visibilidad y rutas.

## Limitaciones importantes
- El inventario individual se muestra y se guarda, pero **no sustituye todavía** los contadores globales de munición y botiquines. No hay pantalla para transferir objetos.
- La búsqueda de rutas se recalcula en cada actualización: requiere caché para mapas grandes.
- Los actores son representaciones geométricas provisionales, no sprites realistas.
- No se ha realizado QA visual ni partida completa; el build depende de instalar paquetes npm.

## Criterios para siguiente versión
1. Unificar mochila y recursos de combate, sin duplicación, y pruebas de intercambio entre supervivientes.
2. Añadir sprites originales, animaciones de ocho direcciones y colisiones visuales.
3. Cachear rutas, estados de alerta, ruido y búsqueda de último avistamiento.
4. Validar compilación, partida completa y guardado/carga en Chromium y Electron.
